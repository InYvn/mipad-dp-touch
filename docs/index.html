Mipad DP Touch

让 小米平板 9 Pro Max 当 Mac 外接屏（DP-in）时，小米焦点触控笔 Pro 真正可用。 不只是移动光标 —— 是能点击、能拖拽、能翻页。 Make the Xiaomi Focus Pen Pro actually usable on macOS when a Xiaomi Pad serves as an external DP-in display.

它解决什么问题

一根 USB-C 全功能线，一个被 macOS 漏掉的翻译层

平板接到 Mac 雷雳口就能当第二块屏（DP-in）。但接上之后，笔的表现取决于你装没装这个工具：

✕ macOS 原生
  • 笔能移动光标，却点不动
  • 点图标、点按钮毫无反应
  • 窗口拖不动，文字也划不了选
✦ 装上本工具
  • 轻点 = 鼠标左键
  • 快速划动 = 翻页滚动，不误选文字
  • 停住再划 = 拖拽：拖窗口、划选文字
  • 停住不动 = 右键菜单
原因不在线材、不在平板：笔的触控走一条独立的 USB 接口。macOS 认得这个设备、能用笔的坐标移动光标，却不把「笔尖按下」当成鼠标左键 —— Windows 接上免驱即用，Linux 原生支持，只有 macOS 缺这层翻译。本工具补的就是这一层。

手指触控在 macOS 上暂时没有可行方案。

功能

菜单栏常驻，随手可用

配置存在你自己的 ~/Library/Application Support/MipadDPTouch/config.json；菜单栏和设置窗口是同一份状态的两个表面，不会「菜单里勾着、窗口里没勾」。

🔍一键放大还不糊

原生分辨率字太小？切到 1704×1136（120Hz，像素 1:1 最清晰），只改平板那块屏，随时换回原档。

🚀开机自启

一个开关，登录后自动就绪；在「系统设置 → 通用 → 登录项」里可见、随时能关。

🧩零侵入、好卸载

不装驱动、不改系统文件；删掉 App 就等于卸载，配置和日志都在你自己的 ~/Library 下。

🎚手感可调

滑动方式、拖拽判定、长按时间、滚动方向与速度都能调，正在排查时可开详细日志。

🔐分步授权引导

① 辅助功能 ② 输入监控，上一步没完成下一步是灰的；TCC 生效要点「立即重启」。

📊事件计数

笔事件 / 点击 / 滚动 / 拖拽 实时计数，笔有没有反应一眼看出来。

快速开始

三步装好

系统要求 macOS 27（在 macOS 27.0 + Mac mini M4 实测；更老的系统未验证，报问题时请带上系统版本）。

  1. 下载安装包

    在 Releases 里下载 Mipad-DP-Touch-1.0.0.dmg（约 13 MB）。

  2. 拖进「应用程序」并打开

    打开 DMG，把 App 拖到「应用程序」，双击打开。装好约占 25 MB；想卸载，退出 App、删掉即可。

  3. 按提示分两步授权

    ① 辅助功能 → ② 输入监控。两项都 ✓ 后点「立即重启」。
    然后用笔点一下图标 —— 能点开就成了。分步图文见 INSTALL.md。

⚠️ 首次打开被系统拦下（ad-hoc 签名，不是文件坏了）

推荐：打开「系统设置 → 隐私与安全性 → 安全性」，点被拦那条的「仍要打开」，再确认一次。或终端一行：

$ xattr -dr com.apple.quarantine "/Applications/Mipad DP Touch.app"
疑难解答

常见的几种情形

更多内容见 INSTALL.md。

想弹右键菜单
笔尖停在原地不动，约 0.8 秒后抬手（设置里叫「长按不动」，可改 0.6 / 1.0 秒，也能关）。停住之后又划走的话仍算拖拽，不会误弹菜单。
笔能点、能翻页，就是拖不动窗口 / 划不了选
先看「滑动方式」：滑动翻页模式下快速划动只用来滚动；要拖拽就把笔尖停住约 0.25 秒再划（长按时间在设置窗口里调，嫌误触可调慢或关掉）。想每一笔都是拖拽，切成滑动选择。
笔点了没反应
十有八九是权限。打开设置窗口的「权限」分区，分步做完两步（辅助功能 + 输入监控），然后点「立即重启」。注意 macOS 27 里「辅助功能」改名叫「设备控制和数据访问」。
更新完 App 就失效了
ad-hoc 签名 + TCC 的老问题：重新授权一次即可。升级时 bundle id 故意保持不变，就是尽量别让你重授权。
字太小 / 太糊
用菜单「显示缩放」切到 1704×1136（带「像素 1:1 最锐」标注）。别去系统设置里拉低分辨率，那样会糊。
找不到窗口，只有一个菜单栏图标
这就是菜单栏应用，没有 Dock 窗口。点菜单栏图标 →「设置…」（⌘,）。
光标不跟着笔走
打开「详细日志」：日志会列出笔的坐标和系统光标的差值。差得明显 = 光标没跟上笔；差值为 0 却点不动 = 事件发出去了、系统没认。
