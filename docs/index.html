Mipad DP Touch Enhanced

小米平板 9 Pro Max，变身 Mac 原生触控屏。

通过 USB-C DP-in 连接，接入 macOS 27.3 系统原生触控。轻点、拖拽、滚动、右键与多指手势，直接在屏幕上完成。搭配小米焦点触控笔 Pro，笔尖上的点击、滚动与拖拽也一并就位。

macOS 27 菜单栏应用 2.0.0-beta 已发布
下载测试版 2.0.0-beta 稳定版 1.2.1 开始使用 ↓
它解决什么问题

一根 USB-C 全功能线，连接平板显示与笔输入

平板接到 Mac 雷雳口就能当第二块屏（DP-in）。但接上之后，笔的表现取决于你装没装这个工具：

无 App、无模块
  • 笔能移动光标，却点不动
  • 点图标、点按钮毫无反应
  • 手指触控无效果
✦ 装上本工具
  • 轻点 = 鼠标左键
  • 快速划动 = 翻页滚动
  • 停住再划 = 拖拽：拖窗口、拖图标
  • 停住不动 = 右键菜单
显示与输入，各司其职。DP-in 显示画面由平板硬件与系统提供，不依赖 App 或模块。App 提供笔手势映射与显示设置；平板模块提供手指触摸接口。

手指触控需要平板侧解锁 —— 装上模块（tablet/）后触摸屏接口就会出现，手指可直接点击、拖拽；旧 v1.0 模块可继续沿用。

功能

菜单栏常驻，随手可用

从笔尖操作到显示缩放，常用功能就在手边。菜单栏与设置窗口共享状态，配置自动保存。

🔍HiDPI 显示缩放

原生分辨率字太小？切到 1704×1136（120Hz，像素 1:1 最清晰），只改平板那块屏，随时换回原档。

🚀开机自启

一个开关，登录后自动就绪；在「系统设置 → 通用 → 登录项」里可见、随时能关。

🎚手感可调

四类手势（轻点 / 快速滑动 / 停住再滑 / 停住不动）各能绑一个动作，滚动方向速度与判定时长都能调，也能一键恢复默认。

🔐分步授权引导

① 辅助功能 ② 输入监控，上一步没完成下一步是灰的；TCC 生效要点「立即重启」。

🖥多屏下笔也能换屏

笔是绝对坐标设备，天然只能在一块屏上动。菜单里选「光标基准屏」即可把笔铺到平板或任意一块在线屏上；默认「跟随光标」保持原有手感。也可以把这个动作绑到某一类手势上（例如「停住不动」），笔上按一下换到下一块屏。

👆系统原生触控

App + 模块在 macOS 27.3 及以上自动选择原生触控，手指输入与多点手势由系统处理，已验证设备自动应用位置修正。

手指触控

手指交给系统，笔继续顺手

App 默认按系统版本与触摸接口自动选择运行方式：macOS 27.2 及以下使用模拟鼠标，27.3 及以上优先系统原生触控。

  1. 沿用平板模块

    旧 mipad-dp-touch-module-v1.0.zip 无需更新。首次安装下载 平板模块 v1.0，在平板的 KernelSU / Magisk 管理器 → 模块 → 从存储安装中选择 ZIP，安装需要平板 root 权限。安装后使用热重启模块完成热重启，再重新连接 USB-C 或进入 DP-in。

  2. 完成系统触控引导

    macOS 27.3 及以上，前往「系统设置 → 无障碍 → 触控 → 触控调节 → 设置」，完成引导并保持触控调节开启。安装、打开 App 与完成系统设置的顺序不限。

  3. 保持自动选择

    「触控与位置」保持「自动 · 推荐」。在「设备概览」查看实际运行方式；原生模式下，已验证设备自动应用位置修正，在「触控与位置」查看状态，退出 App 后恢复。

快速开始

三步装好

Mac 运行 macOS 27；系统原生触控使用 macOS 27.3 及以上。本页界面与功能说明对应 2.0.0-beta，提供 2.0.0-beta 测试版下载，同时保留稳定版 1.2.1。

  1. 安装 App

    1. 下载安装包

      下载 Mipad-DP-Touch-2.0.0-beta.dmg（测试版 2.0.0-beta）。

    2. 拖进「应用程序」并打开

      打开 DMG，把 App 拖到「应用程序」，双击打开。装好约占 25 MB；想卸载，退出 App、删掉即可。

    3. 按提示分两步授权

      ① 辅助功能 → ② 输入监控。两项都 ✓ 后点「立即重启」。
      然后用笔点一下图标 —— 能点开就成了。分步图文见 INSTALL.md。

    首次打开被系统拦下（ad-hoc 签名，不是文件坏了）
    推荐：打开「系统设置 → 隐私与安全性 → 安全性」，点被拦那条的「仍要打开」，再确认一次。

  2. 安装模块（需要 root）

    已有旧 v1.0 模块可继续沿用，无需更新。首次安装下载 平板模块 v1.0 ZIP，保存到平板，在 KernelSU / Magisk 管理器 → 模块 → 从存储安装中选择 ZIP。安装后使用热重启模块完成热重启，再重新连接 USB-C 或进入 DP-in。

  3. 开启触控调节（需要 macOS 27.3+）

    打开「系统设置 → 无障碍 → 触控 → 触控调节 → 设置」，完成引导并保持触控调节开启。安装、打开 App 与完成系统设置的顺序不限。App 的「触控与位置」保持「自动 · 推荐」。
