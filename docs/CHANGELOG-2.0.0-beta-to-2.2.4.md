# 2.0.0-beta → 2.2.4 更新总览

> 只列已经落地、当前版本仍在生效的改动；已回撤或未实现的方案不在其中。

## App

### 连接与解锁

- 新增「便利解锁（不安全）」：可把登录密码存进钥匙串，屏幕已锁且平板刚插上时自动输入；开启前弹出风险确认，关闭即删除密码。
- 新增「断开平板后锁屏」：平板掉线 8 秒后锁屏，只锁屏、不解锁、不碰密码。
- 「断开平板后锁屏」「连接平板时保持唤醒」「便利解锁（不安全）」收进「设备概览 → 连接行为」卡片，三项并排；说明收进标题旁的 ⓘ，点击弹出。

### 插件

- 新增插件市场：可安装 / 更新 / 卸载 / 显示插件，当前提供「屏幕键盘（TouchKeys）」与「浮动工具栏（TouchBar）」。

### 触控与笔

- 兼容模拟改为独占触摸，避免系统与 App 同时派发造成的双落点。
- 纯笔模式新增「独占笔设备」：macOS 27.3 起系统自己也会把笔当数位板处理，与 App 的合成事件叠加会出现一次点击触发多次、拖窗口时左上角同时出现选择框；开启后系统不再接收这支笔。
- 笔改为始终独占，未装模块时也不会与系统叠加出两个落点；独占后由 App 把光标带到平板那块屏。
- 新增「触控可视化」：系统级覆盖层，按真实屏幕位置显示触点与笔的落点（含轨迹），入口在「运行与诊断」，菜单栏也有开关；界面上说明本应用内轨迹可能滞后、切到其他应用正常。

### 界面与稳定性

- 菜单里的「设置…」改为「打开主界面…」——这个窗口除了设置，还有设备概览、插件市场与运行状态。
- 闪退时额外把 Python 调用栈写进 `~/Library/Logs/MipadDPTouch-crash.log`。

## 平板模块

- 设计改为「假 SVID + 注入修正模块」：不再接管厂商 HAL，HAL 仍由系统启动，平板本地触控保留。
- 假 SVID：让固件按「非 Mac 主机」建出「触摸屏 + 笔」二合一接口。
- 注入修正模块：修正双指缩放抬手跳变；gadget 重新枚举时自动重试，少丢帧。
- 版本契约只决定是否注入修正模块：未审计的硬件 / HAL 组合也能安装、SVID 照挂，只跳过注入。
- 新增「立即应用」按钮：一次完成 SVID 与修正模块的布置，并明确报告结果（已生效 / 等待 HAL 重载 / 无法热应用）。
- 卸载会清理运行时状态，重装从干净状态开始；模块只做内存挂载，不写 `/odm` 磁盘、不改 SELinux，卸载后完全复原。
