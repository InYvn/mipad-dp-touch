操作教程

四个手势，看一眼就会

每张卡是一段循环动画：看笔尖怎么动、系统跟着发生什么。

轻点 → 图标点开，App 窗口弹出

轻点 = 鼠标左键

笔尖碰到屏幕就是一次点击。落点取「按下瞬间」的位置，抬手时手抖不会把点击带偏。

›
快速划动 → 整页向上滚动（不选中文字）

快速划动 = 翻页滚动

像滚轮一样，页面真正往上滚。整个动作一个鼠标键都不发 —— 不是划完再取消，是压根没有「按住」这个状态。

›
停住 0.25s → 再划 = 拖着窗口走

停住再划 = 拖拽

笔尖先停住一小会儿（默认 0.25s，可调可关），再划动 —— 拖窗口、划选文字、拖滑块都靠它。

›
停住 0.8s → 抬手 = 右键菜单弹出

停住不动 = 右键菜单

笔尖停在原地约 0.8 秒（可改 0.6 / 1.0 秒，可关），抬手即弹右键菜单。停住之后又划走仍算拖拽，不会误弹。

›

授权只做一次：装好后按设置窗口的分步引导开两项权限（辅助功能 + 输入监控），点「立即重启」生效，之后就不用再管。手感细节（判定时长、滚动方向、速度）都在 配置说明 里逐项解释。
