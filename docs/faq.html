疑难解答

出了状况？先对症，再动手

按现象找处理办法。更深的内容见 INSTALL.md（安装、授权、显示缩放专节）。

各种情形

想弹右键菜单
笔尖停在原地不动，约 0.8 秒后抬手（设置里叫「长按不动」，可改 0.6 / 1.0 秒，也能关）。停住之后又划走的话仍算拖拽，不会误弹菜单。
笔能点、能翻页，就是拖不动窗口 / 划不了选
先看「滑动方式」：滑动翻页模式下快速划动只用来滚动；要拖拽就把笔尖停住约 0.25 秒再划（长按时间在设置窗口里调，嫌误触可调慢或关掉）。想每一笔都是拖拽，切成滑动选择。详见 配置说明 → 笔的输入。
笔点了没反应
十有八九是权限。打开设置窗口的「权限」分区，分步做完两步（辅助功能 + 输入监控），然后点「立即重启」。注意 macOS 27 里「辅助功能」改名叫「设备控制和数据访问」。
更新完 App 就失效了
ad-hoc 签名 + TCC 的老问题：重新授权一次即可。升级时 bundle id 故意保持不变，就是尽量别让你重授权。如果重开开关仍不行，见下面「权限重置命令」。
字太小 / 太糊
用菜单「显示缩放」切到 1704×1136（带「像素 1:1 最锐」标注）。别去系统设置里拉低分辨率，那样会糊。原理见 配置说明 → 显示缩放。
找不到窗口，只有一个菜单栏图标
这就是菜单栏应用，没有 Dock 窗口。点菜单栏图标 →「设置…」（⌘,）。
光标不跟着笔走
打开「详细日志」：日志会列出笔的坐标和系统光标的差值。差得明显 = 光标没跟上笔；差值为 0 却点不动 = 事件发出去了、系统没认。
菜单显示「未检测到设备」
平板没接好，或不在 DP-in 模式。重新插线，看平板是否作为外接屏亮起。线必须是全功能 USB-C 转 USB-C、直连 Mac 雷雳口。
点击、滚动都正常，手指没反应
不是这个应用的毛病，是平板固件的分支。平板的 USB 服务（usb_dp_relay）会先判断主机是谁：认出 Mac（DP Alt Mode 里 SVID 报 Apple 0x05AC）就只创建笔那一路接口，触摸屏那一路的 USB 描述符根本不存在。平板日志原文：adapter_svid: 1452 → host type: Mac → is_mac=1。同一块屏接 Windows 时手指正常，因为走了另一个分支。这个判断发生在接口创建之前，Mac 上任何软件（包括驱动）都改不了，只能等小米固件放开。
滚动方向反了 / 太快太慢
设置窗口「笔的输入」→「滚动方向」选另一个；速度在「滚动速度」里调。默认「跟随系统」，一般不用动。
多屏时「显示缩放」整组变灰
没认出平板那块屏（EDID/名字不匹配）→ 勾「允许管理未实测的显示器」再操作。变灰是保护性设计，防止误改别的屏。
换过分辨率后笔的落点偏了
用菜单里的「显示缩放」切档会自动重算坐标基准，不用重启。如果是在系统设置里改的分辨率，回到 App 菜单随便切一档再看。
什么都不对 / 想全面自检
用 ⌘, 打开设置窗口 →「启动与日志」→「诊断…」跑一遍自检，结果写进日志；「打开日志」看 ~/Library/Logs/MipadDPTouch.log。
权限重置命令（更新后权限失效、且开关重开无效时用）

tccutil reset Accessibility io.github.inyvn.xiaomi-dptouch
tccutil reset ListenEvent io.github.inyvn.xiaomi-dptouch
然后重启 App 重新走一遍分步授权。

无头自检（脚本 / 排障用）

不进 GUI 交互，输出都在 ~/Library/Logs/MipadDPTouch.log：

# 1) 打印真实菜单树 + 认到哪块屏 + 有哪些 HiDPI 档（不改任何设置）
DPTOUCH_SELFTEST_MENU=exit "/Applications/Mipad DP Touch.app/Contents/MacOS/MipadDPTouch"

# 2) 真走一遍「显示缩放」菜单动作：切 1280×853 再切回 1704×1136
DPTOUCH_SELFTEST_DISPLAY=exit DPTOUCH_NO_ALERT=1 "/Applications/Mipad DP Touch.app/Contents/MacOS/MipadDPTouch"

# 3) 设置窗口: 控件树 + 布局质检 + 分步授权/首启引导自检
DPTOUCH_SELFTEST_WINDOW=exit DPTOUCH_NO_GUIDE=1 "/Applications/Mipad DP Touch.app/Contents/MacOS/MipadDPTouch"

DPTOUCH_NO_ALERT=1 让所有弹窗只写日志，脚本/无头跑不会挂住。
