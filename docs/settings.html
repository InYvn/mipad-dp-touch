配置说明

每个设置项是干什么的

2.0.0-beta 设置窗口分为五页：设备概览 / 触控与位置 / 手势映射 / 显示设置 / 运行与诊断。侧栏采用系统玻璃材质，⌘1–5 切页；菜单栏与窗口共用配置，自动保存在 ~/Library/Application Support/MipadDPTouch/config.json。

状态 设备概览

连接状态LIVE

显示当前运行状态：「运行中」「未运行」「等平板上线」。

事件计数COUNTERS

设备概览的 输入事件 实时计数，菜单栏「清零计数」可归零。可在此查看笔输入事件。

权限 设备概览 · 只做一次

权限授权PERMISSIONS

按顺序完成辅助功能与输入监控授权。完成第 ① 步后，第 ② 步可用；窗口自动更新权限状态。

① 辅助功能② 输入监控

① 辅助功能：允许合成点击与拖拽 —— 不开，笔能移光标但点了没反应。按 App 的入口前往系统设置，允许该 App 的辅助功能权限。

② 输入监控：读取平板笔的原始数据 —— 不开，收不到任何笔事件。

立即重启 / 重新检测TCC

macOS 的权限判定发生在进程启动时，授权后点「立即重启」才生效（不用手动退出再打开）。「重新检测」会重新连接并更新状态。

更新 App 后权限失效？ 本 App 是 ad-hoc 签名，按代码哈希记身份，重新打包哈希必变 —— 关掉开关再开没用。终端重置再重启：tccutil reset Accessibility io.github.inyvn.xiaomi-dptouch + tccutil reset ListenEvent io.github.inyvn.xiaomi-dptouch。

触控与位置 触控方式与自动位置修正

自动 · 推荐TOUCH MODE

用原生分段控件选择「自动 · 推荐」「原生触控」「兼容模拟」。默认按系统版本与触摸接口选路：macOS 27.2 及以下模拟鼠标，27.3 及以上优先系统原生；笔继续使用 App 映射。

系统触控设置SYSTEM TOUCH

macOS 27.3 及以上，前往「系统设置 → 无障碍 → 触控 → 触控调节 → 设置」，完成引导并保持触控调节开启。安装、打开 App 与完成系统设置的顺序不限。请安装平板模块 2.0.0，查看安装步骤。

自动位置修正POSITION

App + 模块的原生模式下，已验证设备默认自动应用位置修正（B），本页显示实际修正状态。退出 App 后恢复。

手势映射 原生模式下为笔手势映射

增强模式ENHANCED

匹配平板触摸接口，默认开启。原生模式下手指由系统处理，本页动作、滚动方向和速度继续用于笔。

按键绑定BINDINGS

点当前动作，打开轻量分组菜单更换绑定。一支笔按形态分成四类手势，每一类可绑定一个动作。默认动作见下表；点右上角「恢复默认」可恢复默认绑定。

手势怎么算默认动作
轻点笔尖点一下就走左键单击
快速滑动一笔划过去（位移 ≥ 12px）滚动翻页
停住再滑笔尖先停住一小会儿，然后再划拖拽 · 移动窗口
停住不动笔尖停住又没划走，抬手时算右键菜单

可绑的动作：关 / 左键单击 / 右键菜单 / 中键单击 / 双击 / 滚动翻页 / 拖拽 / 空格键 / 返回 / 切换屏幕。同一个「拖拽」在两个手势下叫法不同 —— 绑在快速滑动上叫「拖拽 · 选中文字」（起手就划，快进快出划选一段），绑在停住再滑上叫「拖拽 · 移动窗口」（先按住在挪）。每类手势列出可用动作（轻点没有位移，就绑不了滚动和拖拽）。

想每一笔都是拖拽？把「快速滑动」的动作改成「拖拽 · 选中文字」 —— 这就是老版本的「滑动选择」模式，现在不需要单独的开关了。

「滚动翻页」发送滚动事件。

切换屏幕 = 把光标基准屏换到下一块在线屏：顺序按桌面排列从左到右、到头绕回第一块，循环。只换笔的落点，不改任何一块屏的分辨率 / 排列 / 镜像；只接了一块屏时按了不动作（日志会写一句）。接了两块以上屏、又不想每次都去点菜单栏时，把它绑到一类手势上（例如「停住不动」）就行了。

组合起来就是一套自己的手感，例如：轻点 = 双击、停住不动 = 空格键（翻 PPT）、快速滑动 = 拖拽；多屏时「停住不动 = 切换屏幕」也很顺手。改完立即生效，不用重启。

滚动方向SCROLL DIR

通过原生分段控件切换，默认跟随系统 —— 跟你 Mac「系统设置 → 鼠标/触控板 → 自然滚动」走的设置。觉得方向反了，选「始终自然」或「始终传统」覆盖即可。

跟随系统（默认）始终自然始终传统
滚动速度SCROLL SPEED

拖动滑条选择滚动速度，显示具体倍率与默认标记；点恢复默认可回到默认速度。

运行 运行与诊断 · 常用开关

启用笔桥接BRIDGE

总开关。临时停用不用拔线；菜单栏也有同名勾选项，两边状态同步。其余不常用的开关都在「高级选项…」小窗里。

显示设置 分辨率与笔目标屏

HiDPI 缩放HIDPI

平板面板原生 3408×2272（13.3″、308 ppi）。按 1x 直接送信号时逻辑 PPI ≈ 308，字比 MacBook Air 小 2.4 倍 —— 这就是「字太小」那档。直接拉低分辨率会糊：帧缓冲小于面板原生，平板要自己放大。

正确做法是切到系统已经生成好的 HiDPI 档（按 2x 渲染、再 1:1 送面板，保持面板原生像素输出）：

档位UI 看起来帧缓冲（真实信号）逻辑 PPI锐度
1704×1136 @120Hz字大了一档，刚好顺手3408×2272（= 面板原生，1:1）≈154最锐，零放大
1280×853 @120Hz字更大2560×1706≈116被平板放大 1.33x，略软
3408×2272 1x（原状）字极小3408×2272≈3081:1 但几乎没法读
更改分辨率DISPLAY MODES

主页面显示当前逻辑分辨率、HiDPI 与刷新率摘要。点「更改…」打开独立模式面板，选择档位后点「应用」才切换；笔坐标基准随之更新。显示设置无需平板模块。

光标基准屏TARGET SCREEN

点击真实在线屏幕排列图，选择笔的光标基准屏；保留「自动」与列表选择入口。也可用菜单栏切换，或把「切换屏幕」绑定到笔手势。这里只改变笔的目标屏。

高级选项 独立小窗

高级选项入口ADVANCED

在「运行与诊断」打开「高级选项…」。高级选项与主窗口共享配置，改完立即生效。

拖拽位置跟随笔尖DRAG SOURCE

拖拽时拿什么当落点。关（默认）= 以按下那一刻的光标为起点、跟着笔尖的位移走 —— 和「轻点」的落点一致；开 = 直接用笔尖在平板上的绝对位置，笔到哪就拖到哪。只在「拖拽的起点总是不对」时才需要开。

允许管理未实测的显示器ALLOW+

多屏时「显示缩放」整组变灰说明没认出平板那块屏 —— 勾上这个才允许操作 EDID/名字不匹配的屏。开启前确认列出的目标屏是平板。

自动检查更新UPDATE

开启后，在启动时静默查一次 GitHub 上的最新版本，之后每天一次；查到了就弹窗告诉你有新版。关闭后停止自动检查。

更新流程是：下载 → 按发版正文里的 SHA256 校验 → 退出程序 → 替换 App（旧版先备份，替换失败时回滚）→ 重新打开。设置和日志都在你自己的 ~/Library/ 下，更新不动它们。检查版本与下载安装包时会联网（api.github.com 查版本、github.com 取安装包）。

立即检查更新CHECK NOW

手动查一次。有新版本会给出更新说明和「下载并安装」；没有则提示已是最新。

停住再滑 / 停住不动的判定时长THRESHOLDS

「停住再滑」默认 0.25s 算停住（四档：0.2 / 0.25 / 0.35 / 0.5s）；「停住不动」默认 0.8s（可 0.6 / 1.0s，选「关」则该手势不再触发）。太灵敏就调慢。停住之后又划走仍算拖拽。

启动与日志

登录时自动启动LAUNCH AT LOGIN

登一下开关，登录后自动就绪。以系统实际状态为准并在旁边显示「已登记为登录项」；在「系统设置 → 通用 → 登录项」里可见、随时能关。

详细日志VERBOSE

排查用。开了之后日志会列出笔的坐标和系统光标的差值：差得明显 = 光标没跟上笔；差值为 0 却点不动 = 事件发出去了、系统没认。日志在 ~/Library/Logs/MipadDPTouch.log，用于查看输入与运行状态。

诊断…SELFTEST

跑一遍自检，把结果写进日志。「什么都不对」时先点它。也支持无头自检，命令见 INSTALL.md。

隐私与卸载

PRIVACY

笔桥接使用两项权限：输入监控（读笔）+ 辅助功能（发鼠标事件）。卸载 = 菜单退出 → 删 App → 删 ~/Library/Application Support/MipadDPTouch/，平板模块在 平板的模块管理器中卸载。
